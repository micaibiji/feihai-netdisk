# 飞海网盘

飞海网盘是一套为飞牛 NAS 与飞牛影视设计的私人网盘影视自动化平台。它保留资源发现、多网盘独立保存、自动追更、统一整理、STRM、字幕/封面元数据和 Telegram 通知，不包含跨盘秒传、磁力离线下载、视频网站下载或 Emby 反向代理。

## 功能范围

- 网盘顺序固定为 115、百度、夸克、中国移动云盘。
- 每个网盘独立保存，不把影视文件跨网盘复制。
- 首页采用适合电视、电脑和手机的影视海报布局。
- TMDB 当日榜单、影视搜索和海报；未配置密钥时显示配置提示，绝不使用虚构榜单或演示海报。
- 后台连接你已有的 PanSou，聚合 Telegram 频道与网盘搜索结果，并自动去重、识别集数和画质。
- 后台连接你已有的 PanCheck 兼容检测站；只展示检测确认有效的链接，检测站故障时明确提示而不误判失效。
- 同一影视可以保存多个网盘来源，按最新季/集、更新时间和网盘顺序自动选源。
- 网盘授权中心同时提供已接通的扫码/官方授权和本机 Token 登录；四个网盘都可粘贴 Token 或 Cookie，并使用 NAS 本机密钥加密保存。
- 网盘凭证使用飞牛 NAS 本机密钥加密，页面和日志只显示脱敏信息。
- 授权过期、网关不可达、访问受限等风控检测；异常时降频或停止，不绕过验证码。
- 飞牛影视统一命名、STRM 与 NFO 生成。
- Telegram 通知、任务记录、设置持久化与移动端管理。

## 当前版本

`v0.4.3` 是正在飞牛 NAS 实机迭代的正式 MVP。当前已经接通真实 TMDB 配置、每页 24 部的全量影视排行与翻页、115 页面内二维码、外接 PanSou 搜索、外接网盘链接检测、同网盘分级目录选择、搜索进度和加密配置，并使用适合桌面与手机浏览器的中文登录页。每个新标签页还会再次验证管理密码，避免已登录浏览器被直接打开。

具体网盘的“保存分享链接”、文件枚举和播放直链必须在对应账号完成授权后，由官方接口或飞海网盘内置连接服务执行。系统不会伪造授权成功，也不会绕过网盘限制。

## 飞牛 NAS 快速启动

第一次安装建议直接按 [飞牛 NAS 可视化安装教程](docs/FNOS_INSTALL.md) 操作，包含目录准备、Compose 创建、页面验收、飞牛影视接入、网盘扫码授权和常见问题。

```bash
cp .env.example .env
# 修改 .env，至少设置强管理密码和 NAS 局域网地址
docker compose up -d --build
```

- 飞海网盘：`http://NAS地址:12366`
- 飞海网盘自身只使用端口 `12366`；你已有的 PanSou 和检测站使用它们原来的地址，飞海网盘不会为它们新开端口。

在飞牛影视中，把 `FNTV_STRM_PATH` 指向的宿主机目录添加为影视库。该目录同时映射到容器的 `/app/strm`。

> v0.4.3 会在飞牛 fnOS 上继续实机验证。外部 PanSou 与检测站的最终联网验收需要先在设置页填写你的实际地址。

建议先建立以下目录：

- `飞海网盘/data`：数据库、加密密钥和任务记录
- `飞海网盘/strm`：提供给飞牛影视扫描的媒体目录
- `飞海网盘/data/gateway`：内置网盘连接数据，由飞海网盘自动管理

## 统一命名

```text
电影/片名 (年份)/片名 (年份).strm
电视剧/剧名 (年份)/Season 01/剧名 (年份) - S01E01.strm
```

相同目录可包含 `.nfo`、`.srt`、`poster.jpg`、`fanart.jpg` 和季度海报。

## 主要 API

- `GET /api/health`：健康检查
- `GET /api/overview`：首页聚合数据
- `GET /api/search?q=片名`：影视作品、Telegram 与网盘并行搜索
- `PUT /api/settings/pansou`：测试并保存自建 PanSou 连接
- `PUT /api/settings/checker`：测试并保存自建链接检测站连接
- `GET/POST /api/subscriptions`：自动追更
- `POST /api/subscriptions/{id}/sources`：为同一影视增加备用网盘链接
- `POST /api/providers/{provider}/auth/start`：启动官方 OAuth 或本机扫码授权
- `GET /api/providers/auth/{session_id}`：查询二维码授权状态
- `POST /api/providers/risk-scan`：授权与网关风控检查
- `POST /api/organize`：生成统一命名的 STRM 与 NFO
- `POST /api/notify`：发送 Telegram 测试通知

除健康检查与登录页外，接口使用登录成功后的本机安全会话。

## 安全原则

- 不使用 Docker host 网络模式。
- 网页录入的凭证使用 Fernet 加密后保存在 `data/credentials`，密钥只在 `data/.credential.key`。
- `.env`、数据库、凭证目录和内置连接数据不可提交到 GitHub。
- 不建议把 `12366` 直接暴露到公网；远程访问请使用 VPN 或带访问控制的反向代理。
- 仅处理你有权保存和使用的文件。
