# 飞海网盘

飞海网盘是一套为飞牛 NAS 与飞牛影视设计的轻量网盘影视自动化平台。它只保留资源入口、网盘转存、TMDB 整理、STRM、追更、Telegram 通知和移动端管理，不包含跨盘秒传、磁力离线下载、视频站下载或 Emby 反向代理。

## 设计范围

- 支持识别 115、百度、夸克和中国移动云盘分享链接，搜索结果按这个顺序排列。
- 每个网盘独立保存，不做跨网盘复制。
- 提供分享链接任务队列、TMDB 搜索、标准化媒体目录和 STRM 生成能力。
- 使用内置 PanSou 服务聚合 Telegram 频道和网盘搜索插件。
- 支持关键词自动追更和 Telegram Bot 通知。
- 提供适合手机使用的中文管理页面。
- 凭证只从环境变量读取，不写入数据库。

## 当前版本

`v0.1.0` 是可运行的基础版本，已经包含：

- Docker 部署和 Basic Auth 管理登录
- 四网盘链接识别与账号配置状态
- SQLite 任务记录
- TMDB 搜索接口
- 安全的 STRM 文件生成
- Telegram / 企业微信通知接口
- 移动端管理页面
- Telegram/网盘聚合搜索与结果优先级
- 关键词追更后台任务

四家网盘的实际“保存分享链接”接口需要分别接入授权凭证。115、百度和中国移动优先采用官方开放平台；夸克采用可替换适配器，避免把非公开协议耦合进核心系统。

## 快速启动

```bash
cp .env.example .env
# 修改 .env，务必设置强密码
docker compose up -d --build
```

浏览器访问 `http://NAS地址:12366`。

在飞牛影视中，把 `FNTV_STRM_PATH` 指向的宿主机目录添加为影视库目录。该目录必须同时映射到容器的 `/app/strm`。

推荐在飞牛 NAS 文件管理器中先建立两个目录，再将它们填入 `.env`：

- `飞海网盘/data`：数据库和任务记录
- `飞海网盘/strm`：提供给飞牛影视扫描的媒体目录

## API

- `GET /api/health`：健康检查
- `GET /api/providers`：网盘连接状态
- `GET /api/jobs`：任务列表
- `GET /api/search?q=片名`：搜索 Telegram 与网盘来源
- `GET/POST /api/subscriptions`：管理自动追更
- `POST /api/intake`：提交分享链接
- `GET /api/tmdb/search?q=片名`：搜索 TMDB
- `POST /api/strm`：生成 STRM
- `POST /api/notify`：发送测试通知

除健康检查外，接口均使用 `.env` 中的管理账号密码进行 HTTP Basic 验证。

## 安全原则

- 不使用 Docker host 网络模式。
- 不在代码或数据库中保存账号 Cookie、Token 和机器人密钥。
- 不建议将 12366 端口直接映射到公网；远程访问请使用 VPN 或有访问控制的反向代理。
- 仅处理你有权保存和使用的文件。
