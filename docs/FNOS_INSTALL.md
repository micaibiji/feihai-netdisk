# 飞海网盘：飞牛 fnOS 可视化安装教程

本教程优先使用飞牛 fnOS 应用中心的一键安装方式。全程只需要一个端口：`12366`，不需要手工创建 Docker Compose 项目。

## 推荐方式：应用中心安装 FPK

1. 从 [GitHub Releases](https://github.com/micaibiji/feihai-netdisk/releases/latest) 下载发布文件 `feihai-drive_1.0.26_all.fpk`。
2. 打开飞牛桌面的 **应用中心**。
3. 点击 **本地安装**，选择下载好的 FPK。
4. 安装设置已预填管理员账号 `admin`、密码 `admin`、PanSou 和检测站地址，确认无误后点击 **安装**。
5. 等待应用状态变成“运行中”，然后从桌面打开 **飞海网盘**。
6. 也可以直接访问 `http://飞牛IP:12366/`。

应用数据由 fnOS 保存到应用专属数据目录。更新 FPK 时数据不会被程序文件覆盖。首次登录后建议到应用设置里修改管理员密码。

下面的 Docker Compose 步骤仅作为旧版本兼容安装方法。

## 安装完成后的结构

```text
飞牛文件管理
└─ 我的文件
   └─ feihai-drive
      ├─ app
      ├─ data                 ← 自动创建，数据库与加密凭证
      ├─ .env                 ← 管理员密码和基础参数
      ├─ docker-compose.yml
      ├─ Dockerfile
      └─ requirements.txt
```

```mermaid
flowchart LR
  A[文件管理：上传并解压] --> B[重命名 .env.example 为 .env]
  B --> C[Docker：Compose 新增项目]
  C --> D[选择解压目录]
  D --> E[创建并启动]
  E --> F[浏览器打开 IP:12366]
  F --> G[管理员登录并完成设置]
```

## 第一步：准备目录

1. 打开飞牛桌面上的 **文件管理**。
2. 进入 **我的文件**。
3. 点击 **新建文件夹**，名称填写 `feihai-drive`。
4. 进入这个新文件夹。

界面位置示意：

```text
┌──────────────────────────────────────────┐
│ 文件管理                                  │
│ [上传] [新建文件夹] [下载] [删除] [更多]   │
│                                          │
│  📁 feihai-drive                         │
└──────────────────────────────────────────┘
```

## 第二步：上传并解压

1. 在 `feihai-drive` 目录中点击 **上传 → 上传文件**。
2. 选择兼容发布包 `feihai-drive-v1.0.26.zip`。
3. 上传完成后，单击压缩包。
4. 点击 **更多 → 解压**。
5. 同名文件处理选择 **解压并覆盖**，然后点击 **确定**。
6. 如果压缩包解压出一层同名文件夹，请进入该文件夹；看到 `app`、`Dockerfile` 和 `docker-compose.yml` 即为正确目录。

## 第三步：建立运行配置

1. 选中 `.env.example`。
2. 点击 **更多 → 重命名**。
3. 改名为 `.env`。
4. 双击 `.env` 或使用飞牛文本编辑器打开。
5. 至少修改下面两项：

```dotenv
ADMIN_USERNAME=admin
ADMIN_PASSWORD=请在这里填写你自己的强密码
```

可直接填写你的服务地址：

```dotenv
PANSOU_URL=http://host.docker.internal:8888
CHECKER_URL=http://host.docker.internal:12110
TEMP_RETENTION_HOURS=48
```

保存后关闭编辑器。不要把 `.env` 上传到 GitHub。

## 第四步：创建 Docker Compose 项目

1. 打开飞牛桌面的 **Docker**。
2. 左侧选择 **Compose**。
3. 点击右上角 **新增项目**。
4. 项目名称填写 `feihai-drive`。
5. “路径”选择刚才包含 `docker-compose.yml` 的目录。
6. 飞牛提示“路径已包含 docker-compose 配置文件”时点击 **确认**。
7. 勾选 **创建项目后立即启动**。
8. 点击 **确认**。

创建窗口示意：

```text
┌────────────── 创建项目 ──────────────┐
│ 项目名称*  feihai-drive              │
│ 路径       …/feihai-drive            │
│ 来源       使用已有 docker-compose   │
│ ☑ 创建项目后立即启动                  │
│                         [取消] [确认] │
└──────────────────────────────────────┘
```

首次构建需要下载 Python 基础镜像和运行组件，通常需要 2 至 5 分钟。日志最后出现 `Started` 和 `Exited:0` 表示 Compose 启动操作完成。

## 第五步：确认运行状态

在 **Docker → Compose** 中应看到：

```text
feihai-drive    ● 正在运行    容器：1
```

浏览器访问：

```text
http://你的飞牛IP:12366/
```

例如：

```text
http://192.168.100.225:12366/
```

如果页面无法打开：

- 确认 Compose 状态为“正在运行”。
- 确认其他应用没有占用 `12366`。
- 在容器的“运行日志”中确认没有红色错误。
- 确认浏览器访问的是飞牛 IP，而不是 `localhost`。

## 第六步：管理员首次登录

1. 点击页面右上角 **管理员登录**。
2. 输入 `.env` 中的 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`。
3. 登录成功后，顶部会显示：

```text
首页｜资源搜索｜我的追更｜任务｜网盘账号｜设置｜退出管理员
```

访客只会看到“首页”和“资源搜索”。

## 第七步：配置搜索、检测和 TMDB

进入 **设置**：

1. **PanSou 地址**：如果和飞海网盘安装在同一台飞牛，保持预填的 `http://host.docker.internal:8888`；如果装在其他设备，填写那台设备的局域网地址。
2. **网盘检测网站**：同一台飞牛保持预填的 `http://host.docker.internal:12110`；其他设备则填写对应的局域网地址。
3. **TMDB API 密钥**：点击页面旁边的“获取与填写教程”申请并粘贴 Key。
4. Telegram 为可选项；需要通知时再填写 Bot Token 和 Chat ID。
5. 点击 **保存设置**。

TMDB 配置完成后，首页会自动出现：

- 动态背景大图；
- 海报和简介；
- “新片”红色标签或排行标签；
- TMDB 评分；
- 剧集/电影、年份、类型、国家地区筛选；
- 翻页。

## 第八步：授权四个网盘

进入 **网盘账号**，按每个网盘支持的方式分别授权，不强求统一：

| 网盘 | 推荐方式 | 页面操作 |
|---|---|---|
| 115 | 支付宝小程序设备类型 | 点击“立即授权”→“显示支付宝小程序端二维码”，再使用 115 手机 App 扫码确认（不是支付宝扫码） |
| 夸克 | Cookie | 从已登录浏览器获取 Cookie 后粘贴 |
| 百度 | Token/授权凭证 | 粘贴可用凭证并保存验证 |
| 中国移动云盘 | Token | 粘贴 Token 并保存验证 |

点击 **测试连接** 后显示“连接正常”，才表示该网盘可以读取目录、同盘保存和准备临时播放。

## 第九步：实际使用

### 访客

1. 搜索影视名称。
2. 检测站明确失效的结果自动隐藏。
3. 任意结果都能复制分享链接。
4. 只有确认存在网页兼容文件时才出现 **播放**。

### 管理员

除访客功能外，还能：

1. 点击 **同盘保存**。
2. 选择首个文件、当前季或全部文件。
3. 选择对应网盘。
4. 逐级进入目标文件夹或新建文件夹。
5. 提交保存任务，并在 **任务** 页查看进度。

## 更新方法

### FPK 安装用户

推荐在飞牛安装一次支持自定义 GitHub 软件源的 **FN软仓**，然后添加下面的软件源地址：

```text
https://raw.githubusercontent.com/micaibiji/feihai-netdisk/main/micaibiji.json
```

以后发布新版时，在 FN软仓的飞海网盘卡片点击 **更新** 即可。更新过程由 fnOS 应用中心执行，应用数据目录会保留。当前版本也可以在 **应用中心 → 本地安装** 中选择更高版本 FPK 完成覆盖升级。

飞海网盘不会为了自更新取得主机管理员权限，也不会因此占用额外端口。待应用通过飞牛官方审核并上架后，可直接从官方应用中心点击升级。

### 旧版 Docker Compose 用户

1. 在 Docker → Compose 中停止 `feihai-drive`。
2. 保留 `.env` 和 `data`。
3. 用新版 `app`、`Dockerfile`、`requirements.txt`、`docker-compose.yml` 覆盖旧程序文件。
4. 在 Compose 项目菜单中选择 **构建**，等待重新创建并启动。
5. 打开 `/api/health` 确认版本号。

不要删除 `data`，否则账号凭证、设置、任务和临时播放记录会丢失。

## 卸载

1. Docker → Compose → 停止并删除 `feihai-drive` 项目。
2. 如需保留设置，先备份 `.env` 和 `data`。
3. 在文件管理中删除程序目录。

删除的是飞海网盘本身，不会删除你的百度、夸克、115 或移动云盘原始内容；但正在使用的“影视临时播放”目录仍可能保留，需要按需在对应网盘中检查。
