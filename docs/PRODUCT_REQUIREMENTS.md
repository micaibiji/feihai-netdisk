# 飞海网盘 1.0 产品需求说明

## 1. 产品定位

飞海网盘是部署在个人飞牛 fnOS 上的网盘影视入口。它负责影视发现、资源搜索、有效性过滤、同盘保存、网页兼容性判断、临时播放和自动清理，不作为公开资源站，也不提供跨网盘秒传。

## 2. 已确认范围

### 首页

- 数据来源：TMDB 实时数据，不放虚构演示数据。
- 顶部动态大图轮播，点击可搜索对应作品。
- 全量按页浏览，从较新、较热门内容向后翻页。
- 筛选维度：剧集/电影、年份、类型、国家或地区。
- 快捷分类：综合、国产、欧美、日剧/日影、韩剧/韩影、动画、纪录片。
- 海报标签：120 天内上映显示“新片”；同时展示 TMDB 评分。
- 点击海报展示简介。

### 搜索

- 后台配置用户自己的 PanSou 地址。
- 合并百度、夸克、115、移动云盘结果，顺序不分先后。
- 按标题匹配度、季集信息和来源时间整理结果，不按网盘强制排序。
- 网盘检测完全使用用户指定的检测网站结果。
- 只隐藏检测网站明确判定失效的链接；有效、待验证、无法验证均显示。
- 所有展示结果均可复制分享链接和提取码。

### 播放

- 先读取分享目录，只有确认网页兼容的具体文件才显示“播放”。
- 不根据标题猜测可播放性。
- 播放时执行同网盘临时保存，不经飞牛远程挂载。
- 临时目录默认名为“影视临时播放”。
- 以最后一次播放时间为准，48 小时无播放后自动删除。
- 浏览器不兼容的资源仍允许复制；管理员也可同盘永久保存。

### 同盘保存

- 百度分享只能保存到百度，夸克到夸克，115 到 115，移动到移动。
- 管理员逐级浏览自己的网盘目录，并选择目标文件夹。
- 可选择首个文件、当前季或全部文件。
- 支持跳过、覆盖或保留两者等重复处理策略。
- 保存任务异步执行，任务页展示阶段、进度和错误信息。

### 权限

- 访客：排行、筛选、搜索、简介、复制、网页播放。
- 管理员：访客全部功能，以及同盘保存、追更、任务、临时文件、网盘账号、设置。
- 不提供访客公开网盘目录，不允许访客永久保存。
- 管理页必须经过账号与密码验证。

### 网盘授权

- 115：页面直接显示二维码，亦可粘贴 Cookie 作为备用方式。
- 夸克：粘贴 Cookie。
- 百度：粘贴可用授权 Token/凭证；待官方应用资格具备后可增加完整 OAuth。
- 中国移动云盘：粘贴 Token。
- 凭证在 NAS 本地加密保存，不上传到外部服务。

## 3. 明确排除

- OpenList 依赖和 OpenList 设置项。
- 飞牛远程挂载作为播放或保存通道。
- 跨盘秒传。
- STRM 生成和飞牛影视目录同步。
- 访客公开目录。
- 为不兼容格式强行显示播放按钮。
- NAS 实时转码 4K、Dolby Vision、DTS 或 TrueHD。

## 4. 外部服务

| 服务 | 用途 | 是否必须 |
|---|---|---:|
| PanSou | 搜索分享资源 | 搜索功能必须 |
| 网盘链接检测网站 | 判断明确失效链接 | 推荐 |
| TMDB | 首页海报、排行、简介和评分 | 首页影视数据必须 |
| Telegram Bot | 保存和追更通知 | 可选 |

## 5. 验收标准

1. `GET /api/health` 返回 `ok`、版本号、单端口策略和 48 小时规则。
2. 未登录时看不到追更、任务、账号和设置。
3. 中文管理员密码可正常登录。
4. PanSou 可返回四类网盘结果，明确失效结果不展示。
5. 未授权网盘时可以复制链接，但不会出现错误的播放按钮。
6. 首页年份筛选可选择快捷年份和 1950 至下一年的完整年份列表。
7. 仅映射 `12366:12366`，Compose 中没有 5244 或其他附加端口。
8. 账号凭证、TMDB Key 和 Telegram Token 不以明文写入数据库。
