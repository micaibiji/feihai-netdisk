# 飞海网盘产品范围（v1）

本文档记录已经确认的正式开发范围。实现时以“真实可用、保守判断、无假数据”为原则。

## 核心流程

1. 使用者在页面内授权 115、百度、夸克或中国移动云盘。
2. 首页从 TMDB 获取真实影视榜单，以海报墙展示电影、剧集及分类。
3. 搜索从 Telegram / PanSou 等已启用来源发现同一影视的多个网盘分享。
4. 后台低频验证分享链接；只有 `valid` 资源出现在普通搜索结果。
5. 入库前再次验证，使用者只能将链接存入同一个网盘，并逐级选择真实目录。
6. 任务完成后按统一规则整理元数据、字幕、封面、NFO 和 STRM，供飞牛影视扫描。
7. 追更可以保存多个来源，按有效性、最新集数、质量偏好和网盘优先级选择当前来源。

## 明确不做

- 不跨网盘转存或秒传。
- 不做磁力、离线下载和视频网站下载。
- 不做 Emby 反向代理，不内置播放器。
- 不自动删除、覆盖或降级已有资源。
- 不绕过验证码、短信验证、频率限制和网盘风控。

## 状态规则

### 资源有效性

- `pending`：等待后台验证，不在普通搜索中展示。
- `valid`：确认可访问，允许展示和入库。
- `invalid`：服务端明确返回失效、取消或不存在；仅在后台日志保留。
- `unverifiable`：网络、限流、验证码或风控导致无法确认；不当作失效，也不在普通搜索中展示。

缓存到期后重新验证；每次入库前强制验证。临时故障不会误删资源。

### 授权

- 页面只显示该网盘实际支持的授权方式。
- 二维码直接显示在当前页面，并显示等待扫码、已扫码、成功、过期和取消状态。
- 账号密码只在对应网盘确实支持时出现；提交后不保存明文密码。
- 登录后的令牌由飞牛 NAS 本机密钥加密，日志和页面只显示脱敏账号。

### 追更选择

排序顺序：有效性 → 最新季/集 → 质量偏好 → 网盘优先级（115、百度、夸克、移动）。
质量更低的来源不得自动覆盖质量更高的现有版本。全部来源失效时暂停并通知。

## 页面范围

- 首次使用向导
- 首页海报榜单与影视详情
- 影视优先的资源搜索、待识别队列
- 我的追更与多来源管理
- 网盘账号、二维码授权、容量与到期状态
- 分级目录选择与入库确认
- 任务中心（搜索、验证、转存、整理、STRM）
- 媒体库、统一命名、元数据与字幕
- 风险中心、通知、数据源管理
- TMDB、飞牛影视、显示、安全、备份设置

## 防误操作

- 入库前显示网盘、分享来源、目标路径和重复处理策略。
- 重复资源可跳过、更新、替换或保留两份，默认跳过。
- 删除、替换和批量操作需要二次确认；可恢复的操作写入历史。
- 后端保留失效和不可验证记录，前台不展示为可用资源。
